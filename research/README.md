# PTR Research Record

This directory keeps architecture claims auditable.

- `novelty/` — claims and prior-art matrix
- `baselines/` — mandatory comparison systems
- `falsification/` — what would disprove each thesis
- `decisions/` — ADRs and architecture decisions
- `catalogs/` — machine-readable open type families, backend slots and component contracts

A component is retained because evidence supports it, not because it sounds novel.

The architecture catalogs intentionally keep unresolved design space visible; `open` does not mean selected or required implementation.
