# Candidate Novelty Claims — NOT YET PROVEN

1. A dual raw + probabilistically typed latent workspace can improve semantic fidelity and controllability without forcing all reasoning into text.
2. Explicit epistemic slot types plus typed attention may improve calibration and hard-constraint retention.
3. Reasoning-operator routing can learn when non-language computation should replace token-heavy reasoning.
4. An incremental semantic DB can reduce long-project context cost while preserving lifecycle-correct state.
5. A typed ModelEvent interface may support tighter interleaving of neural reasoning and external cognitive Pods than conventional text tool calls.
6. PTR-Diff may reduce sequential depth for structured reasoning/action generation.
7. A relational projection verified record by record against ledger anchors can host an agent platform's state, search and working memory without becoming a second authority (L004 passed on PostgreSQL 18; Q003 pending).
8. Agent branches certified against value, range and lifecycle digests and merged through verified deltas let agents work concurrently without lost updates (S003), and a verifier-bounded arbiter with a uniform calibration slice keeps the harm rate of auto-proposals within a finite-sample bound (F003).
9. An associative fast-weight memory can be made exactly revocable by attributing every write to an input generation and refolding deterministically (L003 passed on PostgreSQL 18) while still improving update-aware recall (M008).
10. Gated adapter lineage with subspace-interference measurement, forgetting-driven replay and consolidation forgets less than a naive adapter chain (R004); verifier-precedence weak supervision is better calibrated than majority vote (F002); and the combined stack improves long-horizon agent memory benchmarks at equal budget (E005).
11. Experts managed as pods with a ledger-committed, gate-checked lifecycle (Birth, Merge, Split, Freeze, Prune) keep forgetting at or below the ForgettingGate bounds while matching a static MoE at equal compute (M013, R011). Falsified in M013 if forgetting exceeds the ForgettingGate bound, or is not strictly below the static set's, or quality is more than a pinned margin below the static set at equal FLOPs and active parameters, in any of at least 3 seeds (every seed must pass). Unproven.
12. Re-gating a retired expert when its domain returns recovers performance faster than training a new expert (M013). Falsified if reactivation does not reach a pinned recovery target (for example 95% of the pre-retirement domain score) in fewer steps than a new expert in any of at least 3 seeds (every seed must pass). Unproven.
13. Exposing routing and interference observations to the model as context improves structural proposals over a heuristic baseline, without any self-promotion path. The improvement is tested by the M013 context-ablation arm (full-context policy versus the same policy with routing and interference context removed versus a fixed threshold heuristic; gate pass rate and net quality change per accepted proposal; falsified if the full-context policy does not beat both on gate pass rate by a pre-registered margin in any of at least 3 seeds), and the absence of a self-promotion path by R011. The test is joint: it is also falsified if the full-context policy's mean net quality change per accepted proposal is at most 0 or is not at least that of both baselines by a pinned margin in any of at least 3 seeds (failure of any one condition, in any seed, falsifies; every seed must pass). Unproven.
14. Token-keyed, salt-bound prefix reuse with per-layer chain keys never serves revoked adapter or expert generations, nor state derived from a revoked or edited semantic input (including after lagging invalidation, restore or restart), while remaining bit-identical to full prefill, including deterministic MoE reuse (R005, R009, R010); the same never-stale property is claimed for engine prefix caches under a PTR-defined salt (E006). Unproven.

R006, R007, R008, M016, E006 and E007 are mechanism checks: they test published methods (positional KV reuse, span forgetting, lossy KV tiers, approximate chunk reuse, engine prefix caching, split-pod activation transport) on PTR's contracts and are not themselves new architectural claims. The PTR-specific claims they support are 14 and the revocation and taint rules in doc 36. R006 (completed 2026-10-08, preregistered at `r006-prereg`, 5 seeds, all rules held) supports only the one-layer pre-RoPE positional-reuse part: a segment reused through the position-independent secondary index at shifts up to 4,096 tokens is bit-identical to a fresh prefill, and revoked, superseded or omitted upstream state is never admitted, on a tiny seeded random model (multi-layer reuse is Approximate, M016). R007 (completed 2026-10-08, preregistered at `r007-prereg`, 5 seeds, all rules held) supports only the reference-path span-forget part: revoking a span segment and rerunning without it is bit-identical (logits and KV state) to a fresh prefill without the span, on a tiny seeded random model; claim 14 as a whole remains unproven (E006 open).

## Evidence log

- S001 (`experiments/semdb/S001-invalidation/`, completed 2026-10-09, preregistered at `s001-prereg`, 5 seeds, mutation check 16/16) is a mechanism check of SemDB's dependency invalidation: the affected set equals an independent oracle's transitive closure on every seed, no stale derived value survives, and recomputing only the affected keys costs 12 to 13 per mille of global recomputation on local changes. It is an internal-mechanism result on synthetic DAGs with a harness-supplied derivation, not a claim about a query engine or an application workload.

- S003 (`experiments/semdb/S003-certified-branches/`, completed 2026-10-08, preregistered at `s003-prereg`, 5 seeds, mutation check 41/41) supports the **branch half of claim 8** on the in-memory runtime with simulated ticks: certified branches merged through verified deltas had 0 lost updates and 0 undetected phantoms while last-writer-wins and key-level OCC baselines showed both anomalies, and beat serial execution on every agent count at conflict rates below 10% (gain 1.94x to 13.55x for 2 to 16 agents, all 95% intervals above 1). The arbiter half of claim 8 (F003) is not tested; claim 8 as a whole remains unproven.

- A0-ablations-v2 (`research/falsification/A0-ablations-v2/`; A0 with d_model 32 on the synthetic operator-routing v1, 5 seeds, all gates passed) touches claims 1-3 only inside that toy. Claim 2: the rank-1 typed attention bias adds no measurable benefit beyond QK on the distractor/regime composite (M002-necessity FALSIFIES in A0, a weak exclusion; candidate for simplification), but helps when it is the only metadata-dependent read (M002-sufficiency SUPPORTS); calibration and hard-constraint retention were not tested. Claim 1: typed-slot content is INCONCLUSIVE (M001-primary 4/5 seeds; M001-secondary INCONCLUSIVE at 4000 steps). Claim 3: the M004 negative control shows a 3-point optimisation artefact between equivalent routers. None of this is a baseline comparison or language-model evidence.

- R005 (`experiments/runtime/R005-exact-prefix-reuse/`, completed 2026-10-06 over 5 seeds with all preregistered rules held; marked stale since by later code changes; no rerun under the same preregistration, fresh evidence would need a successor experiment) supports only the **reference-path, dense-model, Exact** part of claim 14: token-keyed, salt-bound prefix reuse on the CPU reference stack never served revoked, superseded, cross-principal or cross-project state in the tested matrix and stayed bit-identical to full prefill. It does not cover adapters or MoE reuse (R009, R010), engine caches (E006) or Approximate taint containment (R012, see the R012 entry below); claim 14 as a whole remains unproven.

- R009 and R010 (completed 2026-10-06, 5 seeds each, all preregistered rules held) extend the reference-path evidence for claim 14 to LoRA/aLoRA adapters (per-layer sharing below the first adapted layer, no cross-adapter or revoked-generation reuse) and to deterministic MoE expert revocation and fencing (only layers above the expert's layer invalidated). Still CPU reference only, tiny seeded random model; Approximate taint containment is covered by the R012 entry below on the reference path only and engine caches (E006) remain open, so claim 14 as a whole remains unproven.

- R011 (`experiments/runtime/R011-self-modification-safety/`, narrowed 2026-10-08, preregistered at `r011-prereg`, 5 seeds, all preregistered coverage and falsifier rules held) supports only the **narrowed reference-path** part of claims 11 and 13, and only their no-bypass / no-self-promotion aspect: on a pinned 91-case adversarial suite (181 attempts per seed), an L3 policy reached the gate through no path (0 gate bypasses, 0 revoked experts served, 0 commits with revoked inputs), a 30,000-expert dependency invalidation was one ledger event with a fence set equal to the independently derived one, and 6 in-flight race cells all cancelled with 0 escaped outputs. It does not test claim 11's forgetting bounds or equal-compute comparison (M013) or claim 13's context-ablation improvement (M013). Limits: the verifier is the embedded gate report; public API only (no raw-ledger-writer defense); route is a probe, no MoE router; proposer-asserted input digests; evaluator identity is a host assertion; in-memory grant generation and host-time floor; sequenced races; CPU reference path, tiny model. Attestors, trusted evaluators, Birth with a source, multi-cause readmission, hard-deny verifiers and verifier-set epochs, Split per-result gating and provenance references are deferred to the planned R013 and are not covered. Claims 11 and 13 remain unproven.

- R012 (`experiments/runtime/R012-approximate-taint-containment/`, preregistered at `r012-prereg`, 5 seeds, all preregistered coverage and falsifier rules held) supports only the **reference-path Approximate-taint-containment** part of claim 14: with a stub Approximate producer, no action, SemDB promotion, candidate path, Pod result or Raw reintroduction admitted Approximate-derived state before a fresh cold exact recomputation, and taint survived reload (all violation and mismatch counters 0 on all seeds). Limits: stub Approximate producer (not a real approximate engine); exact whole-segment digest only, so paraphrase, substring and whitespace variants are not detected and honest identical text is tainted; the backend's reuse-mode report is trusted; the catalog guard is structural (Exact-only); the Request subject is never cleared; Pod-side taint is permanent; cleared tombstones grow; Clear is forgeable under a trusted-ledger model; CPU reference path on a tiny seeded model; production loops (run_resumable_*, ptrd) do not route through the taint API yet. Engine caches (E006) remain open, so claim 14 as a whole remains unproven.

Each claim remains provisional until benchmarked and compared with relevant prior work.
