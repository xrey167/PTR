# Candidate Novelty Claims — NOT YET PROVEN

1. A dual raw + probabilistically typed latent workspace can improve semantic fidelity and controllability without forcing all reasoning into text.
2. Explicit epistemic slot types plus typed attention may improve calibration and hard-constraint retention.
3. Reasoning-operator routing can learn when non-language computation should replace token-heavy reasoning.
4. An incremental semantic DB can reduce long-project context cost while preserving lifecycle-correct state.
5. A typed ModelEvent interface may support tighter interleaving of neural reasoning and external cognitive Pods than conventional text tool calls.
6. PTR-Diff may reduce sequential depth for structured reasoning/action generation.
7. A relational projection verified record by record against ledger anchors can host an agent platform's state, search and working memory without becoming a second authority (L004 passed on PostgreSQL 18; Q003 not run; Q003-v2 stopped INVALID (incomplete); Q003-v3 COMPLETED for the lifecycle guarantees and the dense list's recall, while its lexical half returns nothing on natural-language queries, so a working hybrid is not shown).
8. Agent branches certified against value, range and lifecycle digests and merged through verified deltas let agents work concurrently without lost updates (S003), and a verifier-bounded arbiter with a uniform calibration slice keeps the harm rate of auto-proposals within a finite-sample bound (F003).
9. An associative fast-weight memory can be made exactly revocable by attributing every write to an input generation and refolding deterministically (L003 passed on PostgreSQL 18) while still improving update-aware recall (M008).
10. Gated adapter lineage with subspace-interference measurement, forgetting-driven replay and consolidation forgets less than a naive adapter chain (R004); verifier-precedence weak supervision is better calibrated than majority vote (F002); and the combined stack improves long-horizon agent memory benchmarks at equal budget (E005).
11. Experts managed as pods with a ledger-committed, gate-checked lifecycle (Birth, Merge, Split, Freeze, Prune) keep forgetting at or below the ForgettingGate bounds while matching a static MoE at equal compute (M013, R011). Falsified in M013 if forgetting exceeds the ForgettingGate bound, or is not strictly below the static set's, or quality is more than a pinned margin below the static set at equal FLOPs and active parameters, in any of at least 3 seeds (every seed must pass). Unproven.
12. Re-gating a retired expert when its domain returns recovers performance faster than training a new expert (M013). Falsified if reactivation does not reach a pinned recovery target (for example 95% of the pre-retirement domain score) in fewer steps than a new expert in any of at least 3 seeds (every seed must pass). Unproven.
13. Exposing routing and interference observations to the model as context improves structural proposals over a heuristic baseline, without any self-promotion path. The improvement is tested by the M013 context-ablation arm (full-context policy versus the same policy with routing and interference context removed versus a fixed threshold heuristic; gate pass rate and net quality change per accepted proposal; falsified if the full-context policy does not beat both on gate pass rate by a pre-registered margin in any of at least 3 seeds), and the absence of a self-promotion path by R011. The test is joint: it is also falsified if the full-context policy's mean net quality change per accepted proposal is at most 0 or is not at least that of both baselines by a pinned margin in any of at least 3 seeds (failure of any one condition, in any seed, falsifies; every seed must pass). Unproven.
14. Token-keyed, salt-bound prefix reuse with per-layer chain keys never serves revoked adapter or expert generations, nor state derived from a revoked or edited semantic input (including after lagging invalidation, restore or restart), while remaining bit-identical to full prefill, including deterministic MoE reuse (R005, R009, R010); the same never-stale property is claimed for engine prefix caches under a PTR-defined salt (E006). Unproven.
15. A learned-attention shared workspace (limited slots, competitive top-k write, broadcast read-back) integrates information across specialist modules better, with finite training data and more modules than seen in training, than parameter-matched dense, bandwidth-matched and sparse (top-k) pairwise attention, in a small CPU task where which modules matter is only known after a cue has reached them (C001). A functional-mechanism claim for that setting only, about a learned network and not about the deterministic `ptr-pods::workspace` contract. Three outcomes decided in advance over the declared seeds: supported (every lower one-sided 95% bound at the 30 per mille margin, set a priori as the smallest gain worth a new architectural block; the broadcast, bottleneck and competition contributions are reported as attributed, not attributed or unresolved by noise, using the no-broadcast, capacity-off and competition-off ablations, and never decide the verdict), refuted (guards hold and an upper bound below the margin against a pairwise comparator: the advantage is below the margin, not absent), not shown; saturation, floor, an unconverged arm, an insensitive pipeline or a harness-integrity defect are invalid. Frozen at `c001-prereg`, 20 seeds run: outcome NOT_SHOWN (see the evidence log and the status index).
16. A self-model Pod that sees the MoE's routing traces and internal state predicts the MoE's own errors and uncertainty better than an external probe on input and output, and than the model's own confidence, calibrated against verifier outcomes, while holding no write path to a gate or promotion (C002). GPU stage B planned; the CPU toy stage A (C007) was FALSIFIED (`results/run.json`): no gain over an information-matched probe or over the model's own confidence.
17. A learned model of the router's own routing that is used to control routing (an attention schema) improves reward and load stability over the schema-free router and over a describe-only schema (C003). GPU stage B planned; the CPU toy stage A (C008) was FALSIFIED (`results/run.json`): it beats the schema-free and describe-only routers but not a router that reads the same history directly, so the gain comes from the history, not the schema form.

CPU counter toy COMPLETED (`results/run.json`): supports RPT-1 and the extrapolation clause of RPT-L1 only, close to a known answer; no claim about language models.
