# Training Architecture

Training stages include continued pretraining where useful, typed semantic SFT, native protocol SFT, operator routing, calibration, verifier training, preference optimization, RL and distillation. DSPy/GEPA can optimize teacher pipelines and system policies, while the production runtime remains Rust.

Data splits must include IID, OOD nominal types, unseen Pod names, long-horizon lifecycle cases, semantic corruption, calibration and strong RAG baselines.
