# Definition of Done

PTR is **not** considered a novel or superior architecture merely because the repository is complete.

A major architecture milestone requires:

- controlled baseline with comparable parameter count and compute;
- IID and OOD evaluation;
- unseen Pod-name / known-contract generalization;
- typed hard-constraint fidelity;
- uncertainty calibration;
- token and wall-clock efficiency;
- long-horizon revision/generation correctness;
- crash/restart/revocation invariants;
- strong lexical/vector/RAG baselines;
- ablations for semantic slots, typed attention, latent recurrence, router and verifier loop;
- reproducible artifacts and experiment manifests;
- novelty/prior-art audit updated under `research/novelty/`.

No single benchmark win is sufficient.
