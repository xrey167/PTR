# Evidence

Record reproducible editor-tooling checks here, such as:

- Emacs version and package revision;
- rust-analyzer version;
- open-project/startup behavior;
- rustfmt/check/clippy/test command parity;
- test-at-point behavior;
- macro expansion behavior;
- TRAMP/remote behavior where tested;
- keybinding/command overlap between candidate profiles.

Do not treat popularity or feature count as sufficient selection evidence.
