# E006-engine-prefix-reuse

## Hypothesis
binding an engine's prefix cache to a PTR-derived salt from the currently admitted binding yields at least 1.5x TTFT gain at 50% shared prefix while never hitting stale blocks (blocks created under any revoked or replaced model, adapter or expert generation, or under a pre-revocation salt; the engine salt must include these generations); the run pins, separately for each of the model, adapter and expert generation dimensions, at least one transition (revocation or replacement) followed by stale probes (requests able to hit the old prefix), with stale hits counted and required to be 0 per dimension; with identical binding and numerics, cache-enabled engine output is bit-identical to a cache-disabled full prefill (for engines with batch-invariant kernels); the engine salt carries the principal and the admitted generations and digests but not the semantic lineage, so every semantic or memory input revocation requires an engine-acknowledged flush or salt rotation before further requests are served; blocks are never shared across principals or across dynamic-RoPE scaling regimes (an engine that cannot key per regime is reported not-applicable, never passed); the salt-input transitions are exercised for every salt input (model, adapter, expert, tokenizer, numerics, KvKeyEncoding and RoPE regime), each followed by stale probes; semantic revocation uses per-principal salt-epoch rotation (no global flush, the engine is not required to evict) so principal B's hit rate is unaffected by principal A's revocation; one principal cannot time another's prefix presence (cross-principal TTFT indistinguishability); the engine is vLLM at a pinned version with VLLM_BATCH_INVARIANT=1 on hardware/rtx3090.toml, and a missing batch-invariance makes the run inconclusive, not a pass.

## Primary metrics
ttft_ms, hit_rate, stale_block_hits, model_generation_transitions, adapter_generation_transitions, expert_generation_transitions, stale_block_hits_model, stale_block_hits_adapter, stale_block_hits_expert, stale_probes_after_transition_per_dimension, bitwise_mismatch_count, semantic_revocations_performed, stale_semantic_block_hits, unacknowledged_flushes_before_serve, cross_principal_reuse_attempts, cross_principal_hits, cross_regime_probes, cross_regime_block_hits, ttft_gain, tokenizer_generation_transitions, numerics_generation_transitions, kv_key_encoding_generation_transitions, stale_block_hits_tokenizer, stale_block_hits_numerics, stale_block_hits_kv_key_encoding, stale_semantic_probe_requests, requests_attempted_during_flush_window, flush_window_requests_served, engine_reported_cached_tokens, canary_output_divergence_vs_full_prefill, cross_principal_ttft_ks_pvalue, principal_b_hit_rate_change_after_a_revocation, batch_invariant_verified, unsalted_semantic_control_stale_hits

## Baseline
primary comparator: same engine with prefix caching DISABLED (the denominator of the TTFT gain); secondary control: same engine with caching enabled WITHOUT salt (used only for the stale_block_hits check, where stale-block hits are expected and demonstrate that the salt matters)

## Falsification
TTFT gain against the primary comparator (caching disabled) below 1.5x at 50% shared prefix, or stale_block_hits > 0 with the salted cache (any hit on a block created under any revoked or replaced model, adapter or expert generation, or a pre-revocation salt; the engine salt must include model, adapter and expert generations); the run is invalid and counts as falsified (vacuous) if any of model_generation_transitions, adapter_generation_transitions or expert_generation_transitions is < 1; for EACH dimension separately, at least stale_probe_requests_after_transition stale probes (pinned in config.toml) must be issued after its transition to every arm, the unsalted positive-control arm must show stale_block_hits_<dimension> > 0 (else vacuous), and the salted arm must show stale_block_hits_model == 0, stale_block_hits_adapter == 0 and stale_block_hits_expert == 0 (stale_block_hits is their sum); also falsified by any bitwise difference (bitwise_mismatch_count > 0) between cache-enabled engine output and cache-disabled full prefill under the identical binding and numerics, for engines with batch-invariant kernels; for other engines E006 reports Approximate and cannot claim Exact; also falsified if stale_semantic_block_hits > 0 after a semantic or memory input revocation, or if any request is served before the engine acknowledges the required flush or salt rotation (unacknowledged_flushes_before_serve > 0); the run is vacuous and falsified if semantic_revocations_performed < 1; also falsified if cross_principal_hits > 0 in the cross-principal isolation arm (the same prefix requested by a different principal, cross_principal_reuse_attempts >= 1, else vacuous), or if cross_regime_block_hits > 0 for blocks created under a different dynamic-RoPE scaling regime (cross_regime_probes >= 1, else vacuous); an engine that cannot key blocks per regime, or that must run with caching disabled, is reported not-applicable and never passed; ttft_gain is defined as median ttft_ms with caching disabled divided by median ttft_ms with the salted cache, over the same requests; additionally: a transition followed by stale probes is required for each of tokenizer, numerics and KvKeyEncoding (each transitions counter >= 1, probes >= stale_probe_requests_after_transition, unsalted control stale hits > 0, salted stale_block_hits_<dimension> == 0) besides model, adapter, expert and RoPE regime; stale_semantic_probe_requests >= 8 after a semantic revocation with an unsalted or no-rotation control (unsalted_semantic_control_stale_hits > 0, else vacuous); requests_attempted_during_flush_window >= 1 and flush_window_requests_served == 0 (all queued or rejected); stale hits are detected by engine-reported cached tokens per request (engine_reported_cached_tokens) AND by canary output divergence versus a full prefill under the new binding (canary_output_divergence_vs_full_prefill must be 0 for the salted arm); no global flush is used and principal_b_hit_rate_change_after_a_revocation must be within the pinned tolerance of 0; cross-principal TTFT indistinguishability is tested with a two-sided Kolmogorov-Smirnov test on TTFT of cached versus uncached prefixes of another principal and is falsified if p < 0.01 (cross_principal_ttft_ks_pvalue); the engine is vLLM at the pinned version with VLLM_BATCH_INVARIANT=1 and batch_invariant_verified must be true, otherwise the run is inconclusive, not a pass; the workload is pinned (n_requests, prompt_tokens, shared_prefix_tokens, warmup_requests, concurrency, first request excluded from the TTFT median but included in hit_rate); the lagging or lost invalidation arm (engine flush dropped) and the restore arm (cache restored from a pre-revocation snapshot or engine restart) must each be run (invalidation_suppressed_arms >= 1, restore_arms >= 1) with post_event_lookups >= 1 and stale_hits == 0; every seed must meet every threshold.

## Rule
Record matched baselines, hardware, seeds and negative results. Do not change success criteria after observing results.
