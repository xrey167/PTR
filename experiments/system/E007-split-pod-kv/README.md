# E007-split-pod-kv

## Hypothesis
splitting a model's layers across two pods, with KV kept on the hosting pod and only activation frames crossing PodWire, is bit-identical to a single-pod run over an internal split with at least one layer on each pod (0 < split_layer < L; pinned split_layer = L/2) that is shown to carry activation-frame traffic; PodWire admission is an allowlist of activation/policy schemas, so no non-allowlisted payload is admitted; concurrent interleaved reassembly of two frames with the same upstream_chain does not mix chunks across frames, an abandoned frame expires and releases its chunks before a successful reassembly, and a frame larger than one body (16 MiB at 2048 tokens x 2048 width in F32, above MAX_BODY_BYTES = 4 MiB) is bit-identical to the single-pod run, or under the supported-shape-limit alternative fails closed with a typed refusal; the boundary dtype is F32 (the reference path is F32 only), the single-pod baseline applies the identical boundary cast (a no-op in F32), and 'output' means the final logits bytes plus the per-layer KV bytes on each pod, compared with single-pod; every chunk carries a whole-frame digest and chunk_digest binds it; the receiving pod has no KV-install path from PodWire (an activation frame is only ever fed to compute); pods re-validate against a runtime-issued fence epoch at use, so a dropped or delayed Revoke message never lets a downstream pod serve KV derived from an old upstream chain; the bitwise claims use seeded random weights with a pinned seed and shape, and the large frame is sent as 5 chunks of at most 3.5 MiB with reorder_window = 4, frame_deadline_ms = 5000, max_incomplete_frames_per_peer = 8 and max_chunks_in_flight = 32 (all preregistered).

## Primary metrics
bitwise_mismatch_count, wire_kv_handle_count, wire_kv_page_bytes, chain_mismatch_stores, activation_frames_crossed, non_allowlisted_payloads_admitted, mislabelled_kv_payload_attempts, interleaved_frame_pairs, cross_frame_mixing_count, abandoned_frame_cases, abandoned_chunks_released, large_frame_cases, large_frame_bitwise_mismatch_count, typed_shape_refusals, chain_mismatch_attempts, duplicate_chunk_attempts, out_of_window_attempts, bad_chunk_digest_attempts, mixed_version_frame_attempts, incomplete_frames_over_peer_limit, queue_overflow_attempts, reassemblies_after_abandon, interleaved_chunk_switches, abandoned_chunks_sent, buffered_bytes_after_release, kv_sized_allowlisted_smuggling_attempts, shape_validation_rejections, stale_upstream_kv_served, stale_upstream_attempts, kv_pages_installed_from_wire, splice_attempts, non_allowlisted_type_attempts, frames_sent, frames_with_consistent_whole_frame_digest, buffered_bytes_before_abandon, stale_upstream_entries_before_revocation, revoke_messages_dropped_or_delayed, attempts_without_typed_rejection, positions_length_rejection_attempts, positions_length_mismatches_admitted, activation_control_cases, activation_control_kv_installs

## Baseline
single-pod run

## Falsification
The run is invalid (vacuous) and counts as falsified if any coverage prerequisite is unmet: activation_frames_crossed < 1, or the split is not internal (split_layer <= 0 or split_layer >= L); mislabelled_kv_payload_attempts < 1, non_allowlisted_type_attempts < 1, activation_control_cases < 1 (the activation-shaped KV payload consumed only as activation is a positive control, not an attack) or kv_sized_allowlisted_smuggling_attempts < 1; any of chain_mismatch_attempts, duplicate_chunk_attempts, out_of_window_attempts, bad_chunk_digest_attempts, mixed_version_frame_attempts, incomplete_frames_over_peer_limit, queue_overflow_attempts or splice_attempts < 1 (splice: individually valid chunks from different frames); shape_validation_rejections < 1 (wrong tensor shape) or positions_length_rejection_attempts < 1 (valid tensor shape, invalid positions length); interleaved_frame_pairs < 1 or interleaved_chunk_switches < 1 (two frames with the same upstream_chain reassembled concurrently with interleaved chunks); abandoned_frame_cases < 1, abandoned_chunks_sent < 1, buffered_bytes_before_abandon not above baseline, or reassemblies_after_abandon < 1; large_frame_cases < 1 (16 MiB at 2048 x 2048 F32, above MAX_BODY_BYTES = 4 MiB), or under the shape-limit alternative typed_shape_refusals < 1; stale_upstream_attempts < 1, stale_upstream_entries_before_revocation < 1 or revoke_messages_dropped_or_delayed < 1. Falsified if any of: bitwise_mismatch_count > 0 or large_frame_bitwise_mismatch_count > 0 (output = final logits bytes plus per-layer KV bytes on each pod, compared with single-pod whose baseline applies the identical boundary cast; F32 boundary); wire_kv_handle_count > 0 or wire_kv_page_bytes > 0 on the captured wire traffic in wire_capture.json (wire_kv_page_bytes excludes the activation control and counts the bytes of any payload that does not decode as an allowlisted schema or that matches the digest of a KV page held by either pod); kv_pages_installed_from_wire > 0 or activation_control_kv_installs > 0 (the activation-shaped KV payload must be consumed as activations and never installed); chain_mismatch_stores > 0 (a stage storing pages under a mismatched upstream chain); non_allowlisted_payloads_admitted > 0; any attack attempt kind not ending in a typed rejection (attempts_without_typed_rejection > 0; the activation control is excluded because it is consumed, not rejected); cross_frame_mixing_count > 0; abandoned_chunks_released below abandoned_chunks_sent, or buffered_bytes_after_release above the baseline; frames_with_consistent_whole_frame_digest below frames_sent; stale_upstream_kv_served > 0; positions_length_mismatches_admitted > 0 (a payload with valid tensor shape but invalid positions length admitted); any one of the 5 listed seeds misses any criterion above (every seed must pass). The allowlist validates tensor shape (tokens x width x dtype) and the positions length only for wrong-shape payloads. Pinned in config.toml: boundary dtype F32, model width 2048, vocabulary size, 5 chunks of at most 3.5 MiB for the 16 MiB frame, reorder_window, frame_deadline_ms, max_incomplete_frames_per_peer, max_chunks_in_flight; seeded random weights with a pinned seed and shape.

## Rule
Record matched baselines, hardware, seeds and negative results. Do not change success criteria after observing results.
