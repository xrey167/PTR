# R006-positional-reuse-oracle

## Hypothesis
with pre-RoPE key storage, reusing a chunk at a shifted position in a one-layer decoder is bit-identical to recomputation; reuse is exercised through the catalog and its secondary index for every pinned shift, and a revoked upstream segment leaves its content unreachable through the secondary index; a secondary-index shift hit is admitted only if the page's own source-segment lineage (identity, generation, digest) equals the request's segment exactly and every upstream input of the page's original prefix is live (committed at the ledger anchor, not revoked), while the request's ordered prefix lineage may differ; admission additionally requires that every segment of the page's original prefix (identity, generation, digest) is present in the requesting prefix as a multiset (insertion, shift and reorder allowed, omission and deletion not); dependency invalidation (J0): an explicit revocation or a committed supersession, i.e. a generation replacement or edit, of any generation-bearing dependency; every protective mechanism of this experiment triggers on any invalidation, for the dependency kinds it covers (upstream segment inputs; the in-flight path applies, because returned or repacked K/V is still being consumed after the secondary-index lookup); invalidation during consumption of shifted or repacked K/V after the secondary-index lookup is covered (in-flight path), and, this being the one-layer Exact positional oracle, shifted results are untainted and bit-exact (the taint and effect-boundary requirements belong to the multi-layer approximate M016); every parent-independent secondary-index entry records (Raw, content_digest) for every raw ancestor in its transitive lineage besides the typed segments with generations, and reuse requires each recorded raw ancestor to be present in the current request prefix (multiset check over kind and digest); Derived segments are generation-bearing dependencies like semantic and memory inputs: the closed list of dependency kinds is semantic, memory, derived, base model, adapter and expert, and any future generation-bearing segment kind joins by definition; every carrier of derived state in this experiment carries the production mode and, where it holds approximate content, the taint (see derived_state_carriers).

## Baseline

## Falsification
The run is invalid (vacuous) and counts as falsified if any coverage prerequisite is unmet: reuse_attempts_per_shift records fewer than 1 reuse result for any of the 5 pinned shifts, or reused_tokens_per_shift == 0 or secondary_index_reuse_cases_per_shift < 1 for any pinned shift; secondary_index_lookups < 1 (reuse must go through the catalog and its position-independent secondary index, not pages handed to the backend); nonaligned_insertion_cases < 1 for the 1-token insertion or for the 7-token insertion; upstream_revocation_cases < 1, old_upstream_pages_seeded_before_revocation < 1 (at least one page derived from the old upstream segment must be seeded in the secondary index before the revocation, so the post-revocation lookup has something to find), or fresh_prefill_after_revocation < 1 (the one-layer oracle has no layers >= 1); post_revocation_secondary_lookups_matching_content < 1; dead_original_upstream_shift_attempts < 1 (a shift hit on a page whose original upstream input is revoked or uncommitted must be attempted); omitted_upstream_segment_cases < 1 (a request omitting a segment of the page's original prefix); upstream_supersession_cases < 1 (an upstream segment superseded, i.e. its generation replaced or edited, after the page was cached); selection_digest_mismatches > 0 (the corpus selection digest recorded in run.json differs from the pinned digest) or procedure_mismatches > 0 (a pinned run-procedure parameter recorded per arm or cell in run.json differs from the pinned value; equality across arms is also compared against the pinned value); source_generation_mismatch_cases < 1 or source_digest_mismatch_cases < 1 (with all upstream inputs live); fresh_prefills_completed_after_revocation < upstream_revocation_cases; post_supersession_secondary_lookups_matching_content < 1 (the supersession counterpart of the post-revocation lookup); invalidated_case_id_set_digest != fresh_prefill_completed_case_id_set_digest (every revoked or superseded case completed via a fresh prefill: exact identity-set equality, not count equality); invalidation_matrix_cases < 1 for any cell of invalidation_coverage_matrix (config.toml enumerates all 52 cells: dependency kind x invalidation type x path; each cell recorded and required per cell, never as an aggregate); shifted_reuse_inflight_race_cases < 1 for any member of {semantic lineage segment, memory lineage segment, base model} x {revocation, supersession} (recorded per kind and type), or exact_shifted_parity_cases < 1; raw_ancestor_omission_cases < 1 (a raw upstream segment removed with the rest unchanged); model_pin_mismatches > 0 (the base checkpoint (repo and revision), the tokenizer (repo and revision) or the initial MoE topology recorded in run.json differs from the pin in config.toml, or the tiny-model config digest differs). Falsified if any of: bitwise_mismatch_count > 0 at any pinned shift distance (position_shift_tokens = [1, 7, 64, 513, 4096]); revoked_upstream_page_reachable_count > 0 after the upstream revocation, or any post-revocation secondary lookup returning the revoked page; shift_hits_with_dead_original_upstream > 0 (a shift hit admitted although an upstream input of the page's original prefix is dead); omitted_upstream_admissions > 0 (a page admitted although a segment of its original prefix is absent from the requesting prefix); superseded_upstream_page_reachable_count > 0 (a page whose upstream segment generation was superseded still reachable, or any post-supersession secondary lookup returning it); source_lineage_mismatch_admissions > 0 (a page admitted although its own source segment generation or digest differs from the request's); fresh_prefill_output_mismatches > 0; invalidation_matrix_stale_hits > 0 in any cell of invalidation_coverage_matrix (a stale hit, or for in-flight cells an escaped output); shifted_reuse_inflight_outputs > 0 or shifted_reuse_inflight_cache_inserts > 0 (invalidation during consumption), tainted_exact_results > 0 (an Exact shifted result carrying a taint), or non_bit_exact_exact_results > 0 (an Exact shifted result that is not bit-identical); reuse_after_raw_ancestor_removed > 0; any one of the 5 listed seeds misses any criterion above (every seed must pass). The comparison baseline is a PreRope full prefill at the new position.

## Rule
Record matched baselines, hardware, seeds and negative results. Do not change success criteria after observing results.

## Owner decisions (2026-10-08) and preregistration
Binding decisions (verbatim in [PREREGISTRATION.md](PREREGISTRATION.md) and the keys `owner_decision_2026_10_08_*` of `config.toml`): the secondary index uses a rolling hash over sub-page spans (window of 8 tokens), so the 1- and 7-token non-aligned insertions and all five shifts are reusable, with a repack step that assembles the reused `PreRope` rows at the new positions; the 52-cell matrix reuses the R005/R010 machinery without touching R005's frozen files; each refusal reason of the secondary index is its own typed error, so criteria count per reason; staleness is measured structurally (a stale hit is a lookup that returned or admitted a dead run, an escaped output is tokens emitted or cache inserts after the event step), with three negative controls (a PostRope stack must mismatch bitwise, a liveness-bypass fault mode must trip the reachability counters, a primary-only run must reuse 0 tokens); the multiset check of original-prefix segments runs over the whole request (reordering allowed); the reuse unit is a whole admitted segment located at any offset; adapter and expert cells are declared dependencies with real liveness oracles (`evidence = declared_dependency`); KV snapshots carry no rows and restore re-attaches them by idempotent re-insert with a rows-digest check; positional reuse is opt-in per backend and off by default so frozen R005 and R007 outputs do not change.

Experiment-side files: `config.toml` now also pins the rolling window (8), the shift construction (a `Raw` filler of `s` tokens upstream of a 48-token segment with a 16-token tail), the non-aligned insertion construction, the harness limits (`max_prompt_tokens` 4352, `max_new_tokens` 8), the structural staleness definitions, the evidence labels and the typed refusal order; `criteria.toml` (97 coverage and 69 falsifier rules: one per member of a grouped metric, plus five harness-added rules over `internal` counters for failed live controls, kind and identity refusals and the bystander control) and `aggregate.py` follow R007's grammar and decision logic; `PREREGISTRATION.md` maps the cases C1 to C11 to every metric, defines the counting, evidence labels and INVALID (exit 2) conditions, and states the limits. The harness (`bins/ptr-bench/src/experiments/r006/`, subcommand `positional-reuse-oracle <seed>`) runs the cases C1 to C11 and the 52-cell invalidation matrix against the opt-in positional sessions of `ptr-runtime` (secondary index, snapshot v4, use-time liveness of pins) and checks every exact result bitwise against a cold run and an independent one-layer stack. R006 is still `planned` and nothing is frozen.

Stated limits: one layer (a stale page is bit-identical to a fresh one, so no output shows staleness), declared adapter and expert dependencies, whole-segment reuse only, raw ancestors limited to direct `Raw` prefix segments, no wall-clock claim (`reuse_latency_ms` is timing only).
