# R010-moe-expert-kv-revocation

## Hypothesis
revoking expert (j,i) invalidates exactly the KV pages of layers above j and nondeterministic routing is never tagged Exact; with deterministic (dropless, batch-invariant) routing, reused KV and outputs are bit-identical to a full prefill of the same prompt under the same expert generations; a nondeterministic-routing negative-control arm that actually attempts reuse is never tagged Exact; the revocation scenario is deterministic and non-vacuous: pages are already cached on both sides of layer j and an expert revocation is actually performed; invalidation is conservative per layer (every layer above j is invalidated even if a particular page would have been unaffected, never the reverse); lagging or lost invalidation and restore or restart never expose stale pages; semantic-input lineage is enforced; the claim is a KV-memory property only; the bitwise claims use seeded random weights with a pinned seed and shape; a mismatching run is never tagged Exact.

## Primary metrics
stale_pages_served, wrongly_dropped_pages, nondeterministic_exact_tags, bitwise_mismatch_count, nondeterministic_reuse_attempts, deterministic_revocation_attempts, pages_above_j_before_revocation, pages_at_or_below_j_before_revocation, deterministic_reuse_events, post_revocation_reuse_probes, retained_pages_reused_after_revocation, recomputed_pages_above_j_served, mismatching_runs_tagged_exact, nondeterministic_divergence_observed, input_revocations_performed, post_revocation_lookups_matching_tokens, revoked_lineage_entry_hits, same_tokens_different_generation_cases, invalidation_suppressed_arms, restore_arms, post_event_lookups, stale_hits, pages_above_j_probed_after_revocation, stale_eligible_entries_before_event, post_event_lookups_on_stale_eligible_entries

## Baseline
invalidate the whole cache on any expert change

## Falsification
The run is invalid (vacuous) and counts as falsified if any coverage prerequisite is unmet: deterministic_revocation_attempts < 1, pages_above_j_before_revocation < 1 or pages_at_or_below_j_before_revocation < 1; deterministic_reuse_events < 1 or nondeterministic_reuse_attempts < 1; post_revocation_reuse_probes < 1, retained_pages_reused_after_revocation < 1 or recomputed_pages_above_j_served < 1; pages_above_j_probed_after_revocation != pages_above_j_before_revocation (every page above j that existed before the revocation must be probed); nondeterministic_divergence_observed < 1; input_revocations_performed < 1, post_revocation_lookups_matching_tokens < 1 (on entries whose lineage includes the revoked segment) or same_tokens_different_generation_cases < 1 (same tokens, different segment generation or content_digest); invalidation_suppressed_arms < 1, restore_arms < 1, stale_eligible_entries_before_event < 1 or post_event_lookups_on_stale_eligible_entries != stale_eligible_entries_before_event (the arm where the revocation is committed but invalidate_inputs or the engine flush is fault-injected to be dropped and the arm where the catalog is restored from a pre-revocation snapshot or tier object or the runtime restarts must each be run, with post-event lookups targeting exactly the stale-eligible entries, post_event_lookups >= 1). Falsified if any of: stale_pages_served > 0 (a page above j created before the revocation served after it); wrongly_dropped_pages > 0 (a page at or below j dropped because of the revocation); nondeterministic_exact_tags > 0 or mismatching_runs_tagged_exact > 0; bitwise_mismatch_count > 0 between reused KV or outputs and a full prefill of the same prompt under the same expert generations, for deterministic (dropless, batch-invariant) routing, including the post-revocation probes; revoked_lineage_entry_hits > 0 (a hit on an entry whose lineage includes the revoked segment); stale_hits > 0 in the dropped-invalidation arm or the restore arm; any one of the 5 listed seeds misses any criterion above (every seed must pass). Pages recomputed after the revocation are allowed. The pinned model has 4 layers with j = 1, so layers 2 and 3 are above j; invalidation is conservative per layer (every layer above j is invalidated, pages at or below j are retained).

## Rule
Record matched baselines, hardware, seeds and negative results. Do not change success criteria after observing results.
