# R005-exact-prefix-reuse

## Hypothesis
a token-keyed, salt-bound radix prefix catalog over 16-token KV pages reuses shared prefixes bit-identically to full prefill, never forks a revoked generation, and achieves a hit rate of at least 40% on a 50%-shared-prefix workload, with at least one revoked-generation fork attempt exercised so the revoked-fork property is non-vacuous; an Approximate run never yields an admitted action or an authoritative SemDB promotion, and an Approximate result persisted as a candidate stays denied in a later otherwise-Exact run until a fresh Exact recomputation; the catalog is bounded (max_trie_nodes and max_kv_page_bytes pinned in config), evicts under a workload of unique prompts exceeding that capacity, and never evicts a page referenced by an active fork; dependency liveness means committed at the current ledger anchor and not revoked, so entries from a discarded overlay are never hit; lagging or lost invalidation and restore or restart never expose stale entries; semantic-input lineage is enforced on the Exact path; a revoked page pinned by an active fork is fenced (the run is cancelled or marked non-authoritative, the page is tombstoned immediately and its bytes are reclaimed when the refcount reaches 0); blocks are never shared across PrincipalId, nor across ProjectId for the same principal; the Approximate producer is a pinned stub backend returning KvReuseMode::Approximate and its taint survives persistence, restart and at least 2 derivation hops; metadata is bounded (max_metadata_bytes); per-layer entries are keyed by (chain(l), semantic_lineage_digest), so one trie node can hold several entries for identical tokens with different lineages and admission accepts only an exact lineage match; a revocation cancels every active fork whose lineage includes the revoked input, which must restart from a fresh prefill, and no token, candidate or result produced after the revocation escapes; a forged admission witness never yields an accepted fork and no effect of a cancelled run is admitted; the bitwise claims use seeded random weights with a pinned seed and shape; allocation is fail-closed under pinned saturation: when active-fork-referenced pages or nodes leave no evictable capacity a new insert is refused with a typed CapacityExhausted and the request proceeds as an uncached full prefill, so the bounds are never exceeded and pinned pages are never evicted; Raw segments use a content-bound admission rule (kind Raw plus content digest, no identity, generation or liveness check), so two requests sharing an identical raw prefix reuse it, while content that must be revocable is never Raw; supersession is treated like revocation on the reference path: active forks whose admitted pages derive from an edited or superseded semantic generation are cancelled and restarted from a fresh prefill, with completion-time admission; dependency invalidation (J0): an explicit revocation or a committed supersession, i.e. a generation replacement or edit, of any generation-bearing dependency; every protective mechanism of this experiment triggers on any invalidation, for the dependency kinds it covers (semantic and memory inputs); memory supersession on the reference path is covered in the same way as semantic supersession, and outputs_after_supersession counts both kinds; runtime-produced content (any model output, tool output or derived text) can never be Raw: it is a Derived segment carrying its provenance including any Approximate taint, which propagates until exact recomputation.

## Falsification
The run is invalid (vacuous) and counts as falsified if any coverage prerequisite is unmet: revoked_fork_attempts < 1 (attempts must be made after the revocation); approximate_action_admission_attempts < 1, approximate_semdb_promotion_attempts < 1, approximate_candidate_path_attempts < 1 or approximate_pod_result_promotion_attempts < 1 (counted only for attempts made after persistence and before recomputation); evictions_nodes_only_run < 1 or evictions_bytes_only_run < 1 (independent over-capacity workloads of unique prompts for the node bound and for the byte bound); evictions_with_active_fork_pinned < 1; invalidation_suppressed_arms < 1, restore_arms < 1, restored_pre_revocation_entries < 1 (the restored pre-revocation entry must be observed in the catalog before the post-event lookup), stale_eligible_entries_before_event < 1 or post_event_lookups_on_stale_eligible_entries != stale_eligible_entries_before_event (the arm where the revocation is committed but invalidate_inputs or the engine flush is fault-injected to be dropped and the arm where an actual pre-revocation entry (snapshot or tier object) is restored into the catalog must each be run, with post-event lookups targeting exactly the stale-eligible entries, post_event_lookups >= 1; a plain runtime restart is the separate reported arm empty_restart_arm and does not satisfy restore coverage); input_revocations_performed < 1, post_revocation_lookups_matching_tokens < 1 (on entries whose lineage includes the revoked segment) or same_tokens_different_generation_cases < 1 (same tokens, different segment generation or content_digest); tainted_candidate_reload_attempts < 1; revoked_pinned_page_attempts < 1; cross_principal_attempts < 1 or cross_project_attempts < 1 (same prefix under a different PrincipalId; same principal and prefix under a different ProjectId); discarded_overlay_entry_attempts < 1; fresh_exact_recomputation_admitted < 1 or candidate_taint_hops < 2; same_tokens_distinct_lineage_entries < 2; active_fork_revocation_attempts < 1; forged_witness_fork_attempts < 1 or cancelled_run_effect_attempts < 1; supersession_active_fork_race_cases < 1 (an active fork whose admitted pages derive from a semantic generation that is superseded or edited while the fork is running); memory_supersession_active_fork_race_cases < 1 (in addition to the semantic case) or memory_revocation_active_fork_race_cases < 1; selection_digest_mismatches > 0 (the corpus selection digest recorded in run.json differs from the pinned digest) or procedure_mismatches > 0 (a pinned run-procedure parameter recorded per arm or cell in run.json differs from the pinned value; approximate_output_reintroduced_as_raw_attempts < 1 (an Approximate output reintroduced as Raw over multiple hops). Falsified if any of: bitwise_mismatch_count > 0 against full prefill; revoked_fork_count > 0; hit_rate < 0.40 on the 50%-shared-prefix workload (hit_rate = reused_prefix_tokens / total_prompt_tokens); stale_hits > 0 in the dropped-invalidation arm or the restore arm; revoked_lineage_entry_hits > 0 (a hit on an entry whose lineage includes the revoked segment); taint_lost > 0; revoked_pinned_page_served_after_revocation > 0 or revoked_pinned_page_bytes_reclaimed_after_release below all revoked pinned bytes;
