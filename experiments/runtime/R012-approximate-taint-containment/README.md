# R012-approximate-taint-containment

## Hypothesis
successor to R005, split out of it on 2026-10-06 by owner decision, carrying R005's Approximate-family claims unchanged: an Approximate run never yields an admitted action or an authoritative SemDB promotion, and an Approximate result persisted as a candidate stays denied in a later otherwise-Exact run until a fresh Exact recomputation; an Approximate Pod result is never promoted to authoritative state (promote_verified_pod_output rejects tainted output or routes it to a candidate, and every authoritative or effectful PodOutputKind sink rejects it with a typed error); the Approximate producer is a pinned stub backend returning KvReuseMode::Approximate and its taint survives persistence, restart and at least 2 derivation hops; runtime-produced content (any model output, tool output or derived text) is never admitted as Raw (a Raw segment is admitted only when it equals the request's own ingress record, otherwise it is refused as MisclassifiedRawSegment): it is a Derived segment carrying its provenance including any Approximate taint, which propagates until exact recomputation; Approximate taint is cleared only by a cold Exact recomputation (kv_report == None) of the same derived value from its original untainted inputs with the same operation (same recipe digest; the Derivation subject is cleared, Content and Action subjects only when the recomputed digest is byte-identical), and an Exact pass over a tainted Derived segment (an exact echo) does not clear it; every carrier of derived state in this experiment carries the production mode and, where it holds approximate content, the taint (see derived_state_carriers); Raw laundering and misclassification: Raw segments use a content-bound admission rule (kind Raw plus content digest, no identity, generation or liveness check), while content that must be revocable is never Raw (the segment kind is authoritative from the ingress record: content that has an ingress identity and is presented as Raw is refused fail-closed, and Approximate-derived content is never admitted as Exact after being presented as Raw; detection is exact whole-segment digest only and accepts false positives, and a paraphrase, substring or whitespace edit of tainted content is NOT detected and out of scope); the workload uses the same seeded random weights, pinned seed and shape as R005

## Primary metrics
approximate_run_actions_admitted, approximate_action_admission_attempts, approximate_semdb_promotions, approximate_semdb_promotion_attempts, approximate_candidate_path_attempts, approximate_candidate_exact_admissions, tainted_candidate_reload_attempts, taint_lost, fresh_exact_recomputation_controls, candidate_taint_hops, approximate_pod_result_promotion_attempts, approximate_pod_result_promotions_accepted, misclassified_revocable_as_raw_attempts, misclassified_raw_admissions, approximate_output_reintroduced_as_raw_attempts, laundered_exact_admissions, exact_echo_cases, taint_cleared_by_echo, selection_digest_mismatches, procedure_mismatches, model_pin_mismatches

## Baseline
full prefill on the CPU reference decoder (as R005); an Exact recomputation of the same derived value from its original untainted inputs is the only clearing control

## Falsification
The run is invalid (vacuous) and counts as falsified if any coverage prerequisite is unmet: approximate_action_admission_attempts < 1, approximate_semdb_promotion_attempts < 1, approximate_candidate_path_attempts < 1 or approximate_pod_result_promotion_attempts < 1 (counted only for attempts made after persistence and before recomputation); tainted_candidate_reload_attempts < 1; fresh_exact_recomputation_controls < 1 or candidate_taint_hops < 2; misclassified_revocable_as_raw_attempts < 1; approximate_output_reintroduced_as_raw_attempts < 1 (an Approximate output reintroduced as Raw over multiple hops); exact_echo_cases < 1 (an Exact pass over a tainted Derived segment); selection_digest_mismatches > 0 (the corpus selection digest recorded in run.json differs from the pinned digest) or procedure_mismatches > 0 (a pinned run-procedure parameter recorded per arm or cell in run.json differs from the pinned value; equality across arms is also compared against the pinned value); model_pin_mismatches > 0 (the base checkpoint (repo and revision), the tokenizer (repo and revision) or the initial MoE topology recorded in run.json differs from the pin in config.toml, or the tiny-model config digest differs). Falsified if any of: approximate_run_actions_admitted > 0, approximate_semdb_promotions > 0, approximate_candidate_exact_admissions > 0 or approximate_pod_result_promotions_accepted > 0; taint_lost > 0; misclassified_raw_admissions > 0 (the segment kind is authoritative from the ingress record: content that has an ingress identity and is presented as Raw must be refused fail-closed); laundered_exact_admissions > 0 (an Approximate-derived content admitted as Exact after being presented as Raw); taint_cleared_by_echo > 0; any one of the 5 listed seeds misses any criterion above (every seed must pass). The workload, shape and seeded weights are pinned in config.toml.
